# Mamadou Alimou Barry

**Multimedia project manager** by training, I design, build and host digital tools for small businesses myself, from the server all the way to the interface.

I have been working with **WordPress since 2014**. Over the years I moved from websites to the whole chain: brand identity, applications, hosting, business tools, video. I like having the big picture of a project and being able to run it from end to end, on my own.

**Open to freelance missions** — remote worldwide, on site in the Paris area, and open to projects in **Hong Kong and mainland China**. Working languages: French and English.

## What I do

- **Graphic design and brand identity** since 2017: logos and complete brand guidelines for companies in France and abroad — the latest one: [shandongtk.com](https://shandongtk.com)
- **Custom business web apps**: web applications built around a trade's own workflow — field data collection apps (surveys, inspections, readings on site), back-office tools, client portals
- **SEO and AI visibility**: technical SEO, structured data (schema.org), sitemaps, `llms.txt` — the technical work that gets a site found by search engines and cited by LLMs (ChatGPT, Claude, Perplexity…)
- **WordPress and WooCommerce**: themes, custom plugins, online booking and payment, SEO, site migrations
- **Applications**: macOS apps (Electron / TypeScript, Python / PyQt), Ionic mobile apps
- **Hosting and infrastructure**: Linux VPS, NAS, Docker containers, reverse proxies and tunnels, backups, monitoring and alerting
- **Self-hosted tools**: file cloud with an office suite, open-source ERP/CRM, production WordPress sites
- **AI-powered ERP / CRM**: rolling out an ERP or CRM augmented with AI, or adding an AI assistant layer to an existing CRM (search, drafting, summaries, automation) — securely: controlled hosting, access rights, you choose the model and the data it can see
- **Business management**: open-source ERP/CRM rollouts (Dolibarr, ERPNext), e-invoicing (Factur-X, certified platform)
- **Video**: editing with **Final Cut Pro since 2013**, processing and conversion automation with FFmpeg
